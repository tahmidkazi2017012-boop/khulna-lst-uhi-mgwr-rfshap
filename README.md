# Sprawl-Typology-Driven LST and UHI Dynamics in Khulna, Bangladesh (1990–2025)

Code and processing scripts for the study integrating **Multiscale Geographically
Weighted Regression (MGWR)**, **Random Forest with SHAP (RF-SHAP)**, and the
**Landscape Expansion Index (LEI)** to quantify how urban sprawl typologies drive
land surface temperature (LST) and urban heat island (UHI) dynamics in Khulna,
Bangladesh, using Landsat imagery for eight time points (1990, 1995, 2000, 2005,
2010, 2015, 2020, 2025).

## Study overview

- **Study area:** Khulna, Bangladesh (UTM Zone 46N, EPSG:32646)
- **Data:** Landsat 5 TM and Landsat 8 OLI/TIRS, Collection 2 Level-2 (via Google Earth Engine)
- **Analysis grid:** 500 m fishnet, 14,419 cells per year (after removing missing/no-data)
- **Predictors:** NDVI, NDBI, NDWI, SAVI  |  **Target:** LST
- **Methods:** LST retrieval, spectral indices, LULC classification, LEI sprawl
  typology, MGWR (local spatial regression), RF-SHAP (nonlinear driver importance)

## Methods notes

### LST retrieval
Surface temperature is taken **directly** from the Landsat Collection 2 Level-2
thermal band (ST_B10 for Landsat 8; ST_B6 for Landsat 5), which is an
atmospherically- and emissivity-corrected product generated by the USGS
single-channel algorithm. The band is rescaled to Kelvin using the Collection 2
scaling factors (0.00341802, +149.0) and converted to degrees Celsius. No
additional emissivity correction is applied. Cloud/snow pixels are masked with
QA_PIXEL (bits 3 and 5), a per-year median composite is formed, and a 2nd–98th
percentile filter removes outliers.

### Spectral indices (band conventions)
- Landsat 8 OLI: Green=B3, Red=B4, NIR=B5, SWIR1=B6
- Landsat 5 TM:  Green=B2, Red=B3, NIR=B4, SWIR1=B5
- NDVI=(NIR−Red)/(NIR+Red); NDWI=(Green−NIR)/(Green+NIR);
  NDBI=(SWIR1−NIR)/(SWIR1+NIR); SAVI=((NIR−Red)(1+L))/(NIR+Red+L), L=0.5

### MGWR
Run in **MGWR 2.2** (Oshan et al., 2019): Gaussian model, adaptive bisquare
kernel, AICc bandwidth selection, variables standardized. Per-predictor
bandwidths and local coefficients (β) are exported per year.

### LEI (Landscape Expansion Index)
LEI classification and sprawl-typology (Infilling / Edge-Expansion / Outlying)
change detection were performed in **ArcMap 10.8** following the procedure
described in the manuscript Methods; no scripts were used for this step.

### LULC classification
Per-year supervised classification (Random Forest, 100 trees, 70/30 train/validation
split) was run in Google Earth Engine using manually drawn training polygons for
five classes (Waterbody, Built-up, Vegetation, Agriculture, Bare soil), with
accuracy assessed per year via confusion matrix, overall accuracy, and kappa.
Note: the NDWI definition and minor post-processing vary slightly between years
(documented in each script header) owing to sensor differences (Landsat 5 vs 8)
and iterative refinement; each year's map was validated independently. The scripts
are provided as run, to faithfully reproduce the classifications reported in the study.

## Software / environment

- Google Earth Engine (JavaScript Code Editor)
- Python 3.x with: pandas, numpy, matplotlib, scikit-learn, shap
- MGWR 2.2 (desktop)
- ArcMap 10.8 (LEI classification, β-coefficient map rendering)

## How to reproduce

1. Run the GEE scripts (edit the date range per study year) to export LST,
   spectral bands, indices, and SAVI to Google Drive.
2. Assemble the per-pixel 500 m fishnet CSVs (one per year) with columns
   X_COR, Y_COR, LST, NDVI, NDBI, NDWI, SAVI (see `data/README_data.md`).
3. Run `07_RF_SHAP.py` per year for the RF-SHAP analysis.
4. Run the notebooks `08–10` for diagnostics (VIF, spatial CV), SHAP
   dependence/interaction plots, and the bandwidth figure.
5. Run MGWR 2.2 with the settings above; use the exported β columns to render
   coefficient maps (Point to Raster, 500 m) in ArcMap.
